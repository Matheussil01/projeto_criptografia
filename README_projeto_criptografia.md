## <span style="color:#E10600">Sobre o projeto</span>

Projeto acadêmico em **linguagem C** que combina uma transformação inicial de letras pela **Cifra de César** com uma segunda etapa baseada em sequências numéricas. O código demonstra manipulação de strings, arrays, estruturas condicionais e repetição.

## Funcionalidades

- Aplicação de deslocamento de letras pela Cifra de César
- Seleção por código entre sequências: progressão aritmética, progressão geométrica, Fibonacci e números primos
- Transformação do texto com base na sequência escolhida
- Gravação do resultado em arquivo de texto
- Exemplo configurado no código com a palavra `coracao`, deslocamento 3 e Fibonacci

## Como executar

O programa usa valores definidos diretamente no código-fonte. Para compilar com GCC:

```bash
gcc projeto_criptografia.c -o projeto_criptografia
./projeto_criptografia
```

No Windows, execute `projeto_criptografia.exe`. Consulte também `resultado_criptografia.txt` no repositório.
